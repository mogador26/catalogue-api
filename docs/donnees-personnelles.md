# Données personnelles et cookies

## Ce que ce site collecte

Le catalogue des API est un site de documentation. Il ne comporte ni compte
utilisateur, ni formulaire, ni espace personnel. Naviguer dans le catalogue ne
suppose aucune transmission de données personnelles.

Trois traitements techniques subsistent :

Journaux de connexion
:   Le serveur enregistre les requêtes reçues (adresse IP tronquée, date, page
    demandée, code de réponse) à des fins de sécurité et de diagnostic. Ces
    journaux sont conservés **six mois**, puis supprimés.

Mesure d'audience
:   La fréquentation est mesurée avec une solution configurée pour être exemptée
    de consentement au sens des recommandations de la CNIL : pas de traceur
    publicitaire, pas de recoupement entre sites, adresse IP anonymisée,
    données conservées **treize mois**.

Préférences d'affichage
:   Le choix du thème clair ou sombre est conservé dans le stockage local de
    votre navigateur. Cette information ne quitte jamais votre appareil et n'est
    pas un cookie de suivi.

## Ce que ce site ne fait pas

Aucune donnée n'est transmise à un service tiers à des fins publicitaires.
Aucun bouton de réseau social n'est intégré. Le composant Redoc, qui affiche les
spécifications OpenAPI, est servi depuis ce site et s'exécute dans votre
navigateur : la spécification affichée n'est envoyée à aucun tiers.

Une seule exception à signaler : lorsque vous choisissez d'afficher la
**spécification publiée par le producteur** sur une fiche qui en propose une,
votre navigateur contacte directement le serveur de ce producteur. La copie
hébergée par le catalogue, proposée par défaut, ne déclenche aucune requête
extérieure.

## Cookies { #cookies }

Ce site ne dépose **aucun cookie** soumis à consentement. Il n'y a donc pas de
bandeau à accepter, ni de préférences à régler.

## Vos droits

Pour les journaux techniques, vous disposez d'un droit d'accès, de rectification
et d'opposition, dans les limites prévues par le règlement général sur la
protection des données. Adressez votre demande au délégué à la protection des
données :

- courriel : [dpo@exemple.gouv.fr](mailto:dpo@exemple.gouv.fr) ;
- courrier : Délégué à la protection des données, 1 rue de l'Exemple,
  75000 Paris.

Si vous estimez, après nous avoir contactés, que vos droits ne sont pas
respectés, vous pouvez adresser une réclamation à la
[CNIL](https://www.cnil.fr/fr/plaintes).

## Données traitées par les API

Ce document ne couvre que le site. Chaque API référencée relève d'un traitement
distinct, avec son propre responsable, sa propre finalité et ses propres durées
de conservation. Ces éléments figurent dans la fiche de l'API et, le cas
échéant, dans le registre des traitements de son producteur.
